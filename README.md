# Mapa Ejecutivo

Autoevaluación orientativa de atención, ánimo, sueño y memoria. Usa instrumentos validados y de uso libre (ASRS v1.1 de la OMS, PHQ‑9, GAD‑7, WHO‑5) y genera un informe referencial con un plan de acción.

Se puede instalar en el celular como app (PWA) y funciona sin conexión después de la primera visita. Las respuestas se guardan solo en el teléfono de quien la usa.

**Aviso:** es una orientación referencial. No constituye diagnóstico ni reemplaza la consulta médica.

## Publicar cambios
Edita `index.html` y sube el número de `VERSION` en `sw.js`, para que los teléfonos reciban la versión nueva.
